# Upgrade `symfony-bundle` from 0.1.8 to 0.1.9

What changed in `symfony-bundle` 0.1.9 and what an operator must or may change when upgrading from 0.1.8.
Apply every guide between the deployed version and the target, oldest first, as described in
[upgrade guides](../README.md).

## Changes

- Added: The Symfony bundle is a Symfony AI Mate extension: with `symfony/ai-mate` installed as a dev dependency, the `gauntlet-adapter` tool shows coding agents whether the adapter is enabled and which features, operations, data sources and capability endpoints are registered.

## Steps

No action is required.

## Verify

Install the exact version as described in [installing packages](../../releases/installing-packages.md), then run the
application's framework tests and live conformance before upgrading the control plane.
