# Upgrade `spring-boot-starter` from 0.1.8 to 0.2.0

What changed in `spring-boot-starter` 0.2.0 and what an operator must or may change when upgrading from 0.1.8.
Apply every guide between the deployed version and the target, oldest first, as described in
[upgrade guides](../README.md).

## Changes

- Changed: The Java packages moved to Maven Central under the group `dev.8lines.gauntlet`, so they need no token and no extra repository.
- Changed: Updated `java-core` to 0.2.0.

## Steps

### Maven central (required)

Change the dependency group from `dev.eightlines.gauntlet` to
`dev.8lines.gauntlet`. The Java package names stay `dev.eightlines.gauntlet`, so
no import changes.

Remove the `https://maven.pkg.github.com/8lines/gauntlet` repository and its
credentials from the build. `mavenCentral()` is enough.

## Verify

Install the exact version as described in [installing packages](../../releases/installing-packages.md), then run the
application's framework tests and live conformance before upgrading the control plane.
