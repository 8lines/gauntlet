# Upgrade `gauntlet` from 0.2.3 to 0.2.4

What changed in `gauntlet` 0.2.4 and what an operator must or may change when upgrading from 0.2.3.
Apply every guide between the deployed version and the target, oldest first, as described in
[upgrade guides](../README.md).

## Changes

- Security: Updated the server's MCP SDK to `@modelcontextprotocol/server` 2.4.0 and `@modelcontextprotocol/node` 2.1.2, `zod` to 4.6.7, `fast-uri` to 3.1.9 and 4.2.3, and the dashboard build to `vite` 8.2.4 to clear current dependency advisories.

## Steps

No action is required.

Follow the verification in the [upgrade runbook](../../releases/upgrading.md#verify).
