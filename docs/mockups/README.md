# Dashboard mockups

These files are design references kept to explain visual intent. They are not
copied into the runtime image. The shipping dashboard is built only from
`apps/dashboard/src`.

- `panel.html` preceded the first React implementation in `apps/dashboard`.
- `dashboard-shadcn.html` is the reference for the 0.1.8 redesign on
  shadcn/ui. Use the grey toolbar at the top, or a URL hash such as
  `#operation`, to switch screens. The design rules it follows are in
  [the redesign spec](../superpowers/specs/2026-10-02-dashboard-shadcn-redesign-design.md).
