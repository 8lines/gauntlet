Server setup

The MCP endpoint is off by default. Turn it on where Gauntlet runs.

Set this before starting the server:

GAUNTLET_MCP_ENABLED=true

Set the value in the installation's .env, then run:

./gauntlet up -d --wait

Set this in the values file, then upgrade the release:

mcp:
  enabled: true
