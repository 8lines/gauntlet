# @8lines/gauntlet-widget-channel

Channel-1 message types and strict validators for the postMessage/MessagePort
protocol between the Gauntlet embeddable widget's loader and panel. This
package is private and is bundled into both the loader (`@8lines/gauntlet-widget-loader`)
and the panel; it is never published on its own. See
[docs/superpowers/specs/2026-09-25-embeddable-widget-design.md](../../docs/superpowers/specs/2026-09-25-embeddable-widget-design.md),
section "Channel protocol", for the full protocol design.
